# אטלס הסופות

יישומון לימודי בעברית על שבעה סוגי סופות: הוריקן, טורנדו, סופת רעמים וברקים, סופת שלגים, סופת אבק, סופת ברד וסופת קרח.

האתר כולל הסברים, תמונות המחשה שנוצרו בבינה מלאכותית, הדמיות Three.js אינטראקטיביות, צלילי סופות והתקנה כ־PWA עם שמירה לשימוש ללא אינטרנט.

## מבנה

- `dist/index.html` — עמוד הבית ומעטפת האתר.
- `dist/storms/` — שבע כתובות עמודי הסופות.
- `dist/data.js` — המידע וקישורי המקורות המדעיים.
- `dist/app.js` — תצוגה, ניווט והתקנה.
- `dist/sim.js` — ההדמיות התלת־ממדיות.
- `dist/audio.js` ו־`dist/recordings.js` — צלילים, הקלטות, מקורות וקרדיטים.
- `dist/sw.js` — שמירת קבצים לשימוש ללא אינטרנט.
- `dist/manifest.webmanifest` — הגדרות PWA.

## הפעלה ופרסום

אין צורך בהתקנת חבילות או בתהליך בנייה. להפעלה מקומית:

```sh
python3 -m http.server 8000 --directory dist
```

ב־Vercel יש לבחור Framework: Other ו־Output Directory: `dist`. ההגדרות נשמרות ב־`vercel.json`.

## מקורות ורישיונות

קישורי NOAA, NWS ו־UCAR נמצאים לצד ההסברים וב־`dist/data.js`. ההדמיות מפושטות ואינן מודלים לחיזוי מזג אוויר.

רישיונות ההקלטות אינם אחידים. מקורות, שמות המקליטים, הרישיונות ופרטי העריכה מפורטים ב־`dist/recordings.js` ובחלונות הקרדיט באתר. הקלטת הבליזארד מסומנת CC BY-NC 4.0; יש לשמור על תנאי הרישיון שלה ושל שאר ההקלטות. ספריית Three.js מלווה בקובץ `dist/vendor/THREE-LICENSE.txt`.

## עדכונים

בעת שינוי קבצים שנשמרים לשימוש ללא אינטרנט, יש לעדכן את מזהה המטמון ב־`dist/sw.js` ואת רשימת הקבצים לפי הצורך. ההעלאה הראשונית משמרת את התוכן וההתנהגות של האתר הקיים.

## אמינות וביצועים

- החלק העליון קומפקטי בנייד, והכותרת וכפתור ההתקנה יכולים להישבר לשורות בעת הגדלת טקסט.
- בהשהיה, כשההדמיה מחוץ למסך או כשהעמוד מוסתר, לולאת הציור נעצרת. סיבוב, זום ושינוי עוצמה עדיין מעדכנים את התצוגה המושהית לפי צורך.
- ההסברים, הקוד וספריית התלת־ממד נשמרים כחבילת ליבה. כשל בהורדת תמונה או הקלטה אינו מכשיל את שמירת הליבה. קובץ מדיה חסר נשמר כאשר בקשה מאוחרת אליו מצליחה. שימוש במדיה ללא אינטרנט מחייב שההורדה שלה הושלמה.
- בדיקות ההתנהגות, ללא התקנת חבילות: `node --test tests/*.test.mjs`.
